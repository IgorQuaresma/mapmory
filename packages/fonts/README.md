# @mapmory/fonts

All fonts are licensed under the SIL Open Font License 1.1 (see `licenses/`), which permits embedding in PDFs.
Source: https://github.com/google/fonts (variable TTFs in `variable/`).

`ttf/` holds **static instances, one file per weight** (`<id>-<weight>.ttf`), generated by
`scripts/build-static.py` (fontTools). Static fonts matter because Chromium embeds variable fonts in PDFs as
Type 3 fonts, which prepress checks flag and poppler drops at 300 DPI (docs/adr/0002).

The same static files are used by:
- the browser preview and the print page (`@font-face` in `@mapmory/poster-react/src/fonts.css`),
- Chromium when composing PDFs (embedded as TrueType subsets),
- Martin, which generates the map-label glyph PBFs on the fly (`infra/martin/martin.yaml`).

`noto-sans-400.ttf` is only used as the label fallback for scripts the poster fonts don't cover.
